## 문항 생성 절차

1. 사용자가 **영역** (EDA/전처리/모델링/평가)과 **난이도** (하/중/상)를 지정하면 해당 영역 패턴 파일 참조
2. 영역별 패턴은 `references/` 하위 파일에 있음:
   - EDA 문항 → `references/eda-patterns.md`
   - 전처리 문항 → `references/preprocessing-patterns.md`
   - 모델링 문항 → `references/modeling-patterns.md`
   - 평가 문항 → `references/evaluation-patterns.md`
3. 패턴 파일을 읽어 출제 유형 선택 후 위 포맷으로 출력
4. 복수 문항 요청 시 앞 문항의 결과 변수가 다음 문항 입력이 되도록 연결

## 난이도 기준

| 난이도 | 특징 |
|--------|------|
| 하 | 단일 함수 1~2개, 조건 2개 이하, 직관적 변수명 |
| 중 | 복합 조건 3~4개, 조건부 처리 포함, 주의사항 1개 |
| 상 | 다단계 처리, 함정 조건 포함, 복수 방법 중 선택 필요 |
