# AICE Associate 모의고사 생성 스킬

## 모의고사 구성 규칙

| 영역 | 문항 수 | 권장 시간 | 난이도 비율 |
|------|---------|---------|-----------|
| EDA | 2~3문항 | 15분 | 하:중 = 7:3 |
| 전처리 | 4~5문항 | 30분 | 하:중:상 = 3:5:2 |
| 모델링 | 4~5문항 | 30분 | 하:중:상 = 2:5:3 |
| 평가 | 2~3문항 | 15분 | 중:상 = 6:4 |
| **합계** | **14문항** | **90분** | |

## 핵심 설계 원칙

1. **데이터셋 1개로 전체 연결**: 앞 문항의 결과 변수가 다음 문항의 입력
2. **변수명 흐름 고정**: `df → df_del → df_temp → df_na → df_preset → X_train/X_valid/y_train/y_valid`
3. **난이도 점진 상승**: 영역 내에서 쉬운 것 → 어려운 것 순서
4. **실제 시험 포맷 엄수**: 조건 박스 + 빈 코드 셀 + 정답 접기

## 생성 절차

```
Step 1. 데이터셋 결정
  → aice-dataset-designer 스킬로 데이터셋 설계 or 기존 데이터 사용

Step 2. 변수명 흐름 결정
  → 전체 14문항에서 사용할 변수명 사전 정의

Step 3. 영역별 문항 생성
  → aice-exam-question 스킬의 패턴 파일 참조하여 각 영역 문항 작성

Step 4. 연결성 검증
  → 각 문항의 입력 변수가 이전 문항에서 올바르게 생성되는지 확인

Step 5. 문제지 + 정답지 분리 출력
```

## 요청 처리 방법

1. **데이터셋 지정 있음** → 바로 해당 데이터로 14문항 생성
2. **데이터셋 지정 없음** → aice-dataset-designer에서 시나리오 선택 제안
3. **일부 영역만 요청** → 해당 영역 문항 수만큼만 생성 (모의고사 부분 세트)
4. **난이도 조정 요청** → "쉬운 버전" → 상 난이도 제거, "어려운 버전" → 하 난이도 축소
