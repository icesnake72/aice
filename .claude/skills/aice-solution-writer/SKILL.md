# AICE Associate 풀이 코드 작성 스킬

## 풀이 작성 원칙

- **조건 추적**: 문항의 조건 박스 항목을 코드 주석으로 1:1 매핑
- **변수명 일치**: 문항에서 지정한 변수명을 한 글자도 틀리지 않고 사용 (채점 기준)
- **단계 주석**: `# [단계N]` 형식으로 각 처리 단계 명시
- **결과 확인**: 풀이 마지막에 `print()` 또는 `display()`로 결과 출력
- **함정 경고**: 틀리기 쉬운 부분은 `# ⚠️` 주석으로 강조

## 출력 구조

### 1. 조건 분석
```
[조건 분석]
✅ 조건1: {코드로 구현할 내용}
✅ 조건2: {코드로 구현할 내용}
⚠️ 주의: {함정이나 헷갈리는 부분}
```

### 2. 풀이 코드
```python
# 필요한 import
from sklearn... import ...

# [1단계] {조건1 구현}
변수명 = ...

# [2단계] {조건2 구현}
결과_변수명 = ...

# 결과 확인
print(결과_변수명)
```

### 3. 해설
```
[해설]
- 왜 이 함수를 썼는지
- 파라미터 의미
- 다른 방법과의 차이점 (있는 경우)
```

### 4. 자주 하는 실수 (해당 문항에 해당하는 경우만)
```
⚠️ 이 문항에서 자주 틀리는 것:
- {오답 패턴}: {올바른 방법}
```

## 자주 나오는 함정 패턴 (풀이 시 항상 체크)

```
□ mode()[0] — fillna(df['col'].mode()) 아니라 mode()[0] 인덱싱 필수
□ 스케일링 — X_valid에 fit_transform 대신 transform만 사용
□ 변수명 오타 — df_clean vs df_Clean 대소문자
□ axis 방향 — drop(..., axis=1) 컬럼, axis=0 행
□ train_test_split 반환 순서 — X_train, X_valid, y_train, y_valid
□ 다중 분류 f1 — average='macro' 또는 'weighted' 지정 필수
□ predict_proba — ROC-AUC용, [:, 1]로 양성 클래스만 추출
```
